
# IDC-CALC

Desenvolvido por Reinaldo Sousa.

## Sobre o projeto

Calculadora de produção industrial desenvolvida em Python, com o objetivo de aprender, praticar e aprimorar minhas habilidades em programação.

## Funcionalidades

- Registrar produção por horário.
- Modificar produções existentes.
- Registrar tempo de produção em minutos.
- Mostrar um resumo com a produção de cada horário.
- Calcular a produção total.
- Calcular a produtividade média por hora.

## Tecnologias utilizadas
- **Python**
- **Git**

## Requisitos

- Python 3 instalado
- Terminal para executar o programa
- Não necessita de bibliotecas externas


## Como executar

1. Acesse o repositório no GitHub.
2. Clique em **Code > Download ZIP**.
3. Extraia o arquivo baixado.
4. Abra a pasta extraída no VS Code.
5. Abra o terminal na pasta principal.
6. Execute:

```bash
python IDC-CALC/main.py
```

### Execução alternativa

Caso prefira entrar diretamente na subpasta que contém o arquivo `main.py`, execute:

```bash
cd IDC-CALC
python main.py
```
